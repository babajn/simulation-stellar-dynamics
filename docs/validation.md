# 修正履歴と検証方法

対象は、講義「シミュレーション天文学」の実演用Notebook全10本です。検証は計算モデルの適用範囲を広げるものではありません。講義スライドの訂正とNotebookとの対応は、[講義スライドと正誤表](lecture-slides.md) にまとめています。

## 2026年11月12日の査読後改訂

- **ex01:** 強い減衰での相対誤差と漸近領域の説明を追加。時間計測を統一。
- **ex02:** 陽的中点法の数式を実装に一致させ、Heun法との違いを明記。線形自律例では両者が重なることを説明。非線形比較例の追加は保留。
- **ex03–04:** 重複する解法の説明を既出Notebookへの参照に整理。Adams法は修正1回のPECE型として、安定性と関数評価回数を訂正。ABM2は定常ステップ3回、ABM4は5回の評価で、履歴保存による最適化は行っていない。
- **ex05:** Leapfrogのシンプレクティック性とエネルギーの厳密保存を区別。KDK更新式を掲載。円軌道の位置誤差・エネルギー誤差・計算時間を並べ、位置誤差に参照傾きを追加。長時間積分の軽量モードを追加（既定は全長）。色と線種・マーカーを併用。
- **ex06a/b:** `G` を明示し、挿入と重力計算を `notebooks/tree_core.py` に共通化。最大深さ64、任意の詳細表示、子ノードの方角を統一。力の誤差は平均・中央値・最大相対誤差・最大絶対誤差で表示。小さい真の力で相対誤差が大きくなる点を説明。
- **ex07a/b:** 密度再構成の説明と呼び出しを一致させ、コメントの格子点数を訂正。単極＋双極分布を表す関数名に変更。球面調和関数の表示格子を60×60へ細分化。
- **ex08:** 再構成ポテンシャルを重力定数 `G` に比例させる。基底自体は $G=1$ の規約。有限積分範囲・格子による誤差を図の直前に説明し、基底次数の図の表記を訂正。
- **文書:** 補助資料の数式表記を修正。公開準備用メモを配布対象から除外。ライセンスは未設定。

## 初回整備で行った主な修正

時刻配列と実際の刻み幅の統一、陰的解法の残差確認、Adams法の短い積分区間への対応、Kepler問題の力・比エネルギーと配列長の整合、ツリーの自己力除外と重心距離ゼロの場合の処理、乱数固定、SciPyの `sph_harm_y` への移行、密度関数を区別するキャッシュ、球面調和展開の角度積分、HO92係数の規格化とスケールの整理を行いました。

## 再現方法

READMEの環境を作成し、リポジトリ直下で実行します。

```sh
python scripts/validate_physics.py
python scripts/validate_ellipsoid.py
python scripts/execute_notebooks.py --timeout 900
python scripts/check_release.py
```

`validate_physics.py` はNotebookの関数・クラス・importと、Notebook内で定義されたリテラル定数を読み込みます。存在しない `G` 等を検証側で補いません。図の生成や長時間の実演は全セル実行で別途確認します。

検証項目は、ODEとKepler軌道の収束次数、陰的解法の残差、角運動量と時間反転、ツリーと独立な直接和、不等質量・自己力・1000粒子の挿入、Adams法の関数評価回数と安定性、球面調和射影とポテンシャル、HO92の規格化・Poisson方程式・密度とGに対する線形性です。楕円体は独立な1次元積分と比較します。

線形試験方程式の負の実軸に沿った安定区間はABM2で $[-2,0]$、ABM4で約 $[-1.285,0]$ です。複素平面全体の安定領域や非線形問題での安定性を、この区間だけで判断することはできません。

## 検証記録と限界

改訂版の全10本・93コードセルは独立Pythonプロセスで実行成功し、41枚の図と四分木GIFを生成しました。ex05の100万ステップ比較2組は短縮していません。数値検証8項目と楕円体の独立照合も成功しています。円軌道Leapfrogの位置誤差の観測次数は1.99983、エネルギー誤差の傾きは3.99955で、両者を区別できています。ツリーの直接和との差は最大約2.13×10⁻¹⁴、楕円体の軸上相対誤差は教材格子で最大約1.92%、細分格子で約1.00%です。

`docs/verification/` に実行結果と数値指標を保存します。`execution.json` の実行方式は独立Pythonプロセスです。`baseline.json` は初回整備時に修正前の教材を調べた記録です。実行時間には同時実行の負荷も含まれるため、手法間の厳密な速度比較には使用しないでください。全セル実行は新規カーネルで行い、共有モジュールも実行先へコピーします。実行済みNotebookとGIFは `build/` 以下に保存し、配布Notebookの出力は空にします。

今回の環境ではJupyterカーネルの通信開始が権限制限で失敗したため、改訂版は `python scripts/execute_python.py` によるNotebookごとの新規Pythonプロセスで全コードセルを実行しました。コードセルの内容は変換せず実行し、MatplotlibのAgg描画で図を保存します。これはJupyterフロントエンドでの数式・ウィジェット表示の確認ではありません。Jupyter用の全実行スクリプトは引き続き提供していますが、改訂版のカーネル全実行は未確認です。

macOS arm64 / Python 3.12が直接の検証環境です。査読では改訂前のコミット `cccf37d` に対しLinux / Python 3.12.3で全実行成功が報告されています。これは今回の改訂版のLinux動作検証ではありません。Windows・Colabは未検証です。計算時間は機種や負荷に依存します。

円軌道では保存量の誤差に相殺が起き、解そのものの次数と異なる傾きが出ます。有限積分範囲・有限次数・不連続な密度境界の影響は、格子と領域を別々に変えて評価してください。楕円体の既存の照合は約1%の精度までで、任意の分布に対する精度を保証しません。softening、適応刻み、バケット葉の追加はこの改訂の対象外です。

公開点検スクリプトは配布ファイルの秘密情報パターン・ローカルパス・メール形式・巨大ファイル・出力欄を検査します。Gitのコミット作成者情報や、第三者の著作権の来歴は検査対象に含みません。過去のコミット作成者情報は変更していません。
