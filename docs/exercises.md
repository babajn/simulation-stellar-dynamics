# 数値実験の学習目標と判定基準

講義の実演をさらに調べたい場合の任意の補助課題です。解析解、保存量、解像度を変えた比較で検証します。基準値は無次元量です。`scripts/validate_physics.py` が基本チェックを再現します。

## ex01–04 時間積分

試験方程式 $y'=-2y$, $y(0)=1$ を $T=1$ まで積分し、$E(h)=|y_N-e^{-2}|$ と $p=\log_2[E(h)/E(h/2)]$ を求めます。$h=1/40,1/80$ でEulerは約1、Heun・中点・ABM2は約2、RK4・ABM4は約4（目安±0.25）です。さらに刻みを小さくして丸め誤差の飽和を説明してください。

時間区間を刻みで割り切れない場合、$N=\max(1,\operatorname{round}[(T-t_0)/h])$、実際の刻みを $(T-t_0)/N$ とします。要求したhと実際のhが異なる場合があるので、収束図には `t_values[1]-t_values[0]` を用います。負の刻み・空の時間区間は拒否します。

非自律問題 $y'=t$, $y(2)=0$ の $y(3)=2.5$ も試し、時間配列と更新刻みの整合性を確認します。例示された指数関数の解析解は $t_0=0,y_0=1$ 用です。一般の初期値では $y_0\exp[-\alpha(t-t_0)]$ に変更します。

非線形減衰 $y'=-\alpha y^2$ の解は $y_0/[1+\alpha y_0(t-t_0)]$ です。後退Eulerは各ステップの残差を確認します。Newton法の初期値・許容誤差にも依存します。

前進Eulerの減衰条件は $0<\alpha h<2$。境界 $\alpha h=2$ では振幅が減衰しません。ABMは予測値で修正を1回評価するPECE方式で、陰的AMを完全に解く方法の安定領域と区別します。元の教育実装は過去の傾きを毎回再評価するため、理論上の最小評価回数を実現する最適化実装との速度比較には使えません。

## ex05 Kepler軌道

単位は $G=M=1$、時間単位は一般には $\sqrt{a^3/(GM)}$。力は $-GMm\mathbf r/r^3$、加速度は $-GM\mathbf r/r^3$、比エネルギーは $E=v^2/2-GM/r$ です。

円軌道 $\mathbf r_0=(1,0),\mathbf v_0=(0,1)$ は $\mathbf r(t)=(\cos t,\sin t)$。終点 $T=1$ の位置誤差で収束次数を測ります。エネルギー誤差だけでは位相精度を保証しません。全手法のグラフは $|E(t)-E(0)|$ で比較します。

楕円軌道 $\mathbf v_0=(0,0.7)$ では、Leapfrogを $h=0.002,T=20$ で実行し、$L_z=xv_y-yv_x$ の変動と速度を反転した逆向き積分を調べます。検証の許容値は角運動量 $10^{-11}$、復帰位置・速度誤差の和 $10^{-8}$。刻みは固定です。長時間例を短縮した場合は、元の100万ステップ実験と区別して結果に記録してください。

## ex06a–b ツリー法

四分木による2次元位置の分割と、3次元Newton重力の逆二乗則を組み合わせています。2次元Poisson方程式の対数ポテンシャルではありません。計算結果は力なので、加速度にするには対象粒子の質量で割ります。

乱数種を固定して、同じ配置の直接和とθ=0のツリー和を比較します。相対・絶対許容誤差 $10^{-12}$ が目安です。θ=0.1,0.3,0.5,1について中央値・最大誤差・時間を測り、配置によって単調性が保証されないことも確認します。直接和が小さい場所では相対誤差が発散的に大きくなるので絶対誤差も示します。

対象を含むセルは開きます。対象位置がセル重心と一致しても、非対称な子粒子の力がゼロとは限りません。原点に質量1、x=1に質量2、x=-2に質量1を置くと原点の力は+1.75です。自己力除去の回帰例です。同位置粒子・領域外入力は例外にします。深さ上限の例外後は木を作り直してください。無softeningの近接遭遇を伴う実用N体シミュレーションには拡張が必要です。

## ex07b–a 球面調和関数

$\theta$ は極角、$\phi$ は方位角。SciPy `sph_harm_y(l,m,theta,phi)` はCondon–Shortley位相を含む正規直交な複素基底です。係数は $\rho_{lm}=\int\rho Y_{lm}^{*}d\Omega$。一様密度の内部では $\rho_{00}=\sqrt{4\pi}$、$\rho=\cos\theta$ なら $\rho_{10}=\sqrt{4\pi/3}$、他のモードはほぼゼロです。

24×48点と48×96点の角積分で、滑らかな低次の例が $10^{-12}$ 以下で一致することを確認します。不連続なトーラスや高次モードではさらに格子を細かくしてください。キャッシュは密度関数の同一性をキーに含みますが、その関数が参照するグローバル変数を変更した場合は `compute_rho_lm.cache_clear()` と `cached_compute_rho_lm.cache_clear()` を実行してください。

一様球の内外のポテンシャルと解析解を比較します。Plummer球を $r_{\max}=10$ で打ち切ると、$M=b=G=1$ では内部ポテンシャルが $(1+10^2)^{-3/2}\simeq9.85185\times10^{-4}$ だけ浅くなります。有限積分範囲の系統誤差であり、丸め誤差ではありません。$r=0$ はこの関数の入力範囲外です。

`dipole_distribution` は符号付きの数学的試験関数です。`monopole_dipole_distribution` は単極＋双極の角分布であり、一様密度三軸楕円体ではありません。

## ex08 基底関数展開

$G=a_{\rm basis}=1$、$Y_{00}=1/\sqrt{4\pi}$ として、$n=l=0$ の基底対を組み合わせるとHernquistの $\Phi=-1/(1+r)$、$\rho=1/[2\pi r(1+r)^3]$ です。

双直交規格化 $I_{nl}=\int_0^\infty\rho_{nl}\Phi_{nl}r^2dr$、非対角積分の消失、$\Phi''+2\Phi'/r-l(l+1)\Phi/r^2=4\pi\rho$ を独立に確認します。コードは密度を積分して係数を求めるので、ポテンシャルへさらにM/Rを掛けません。密度を2倍にするとポテンシャルも2倍です。基底自体はG=1の規約ですが、再構成の最後にGを掛けるため、Gを2倍にしてもポテンシャルが2倍になります。

有限格子の結果を厳密解と同一視しないでください。特に一様球の密度不連続では、次数だけを増やすと粗い積分格子の誤差を拾います。Hernquistの零次モードは半径 $10^{-5}$～$10^3$、対数格子4001点、角度65×65点で相対誤差 $10^{-5}$ 以下を判定基準としています。この検証格子は教材の軽量な表示用格子と異なります。三軸楕円体は独立した楕円体ポテンシャル積分と比較して、教材格子で最大約1.92%、細分化した格子・高次数で約1.00%の軸上相対誤差でした。研究利用には目的精度までのさらなる収束確認が必要です。`python scripts/validate_ellipsoid.py` で再現できます。

## 収束図の読み方

観測次数は漸近領域で複数の刻みの組から確認します。丸め誤差や位相誤差の相殺が強い範囲では、1組の比から次数を判断できません。円軌道のエネルギー誤差は、位置誤差より高い次数で減少する場合があります。ex05では位置誤差とエネルギー誤差を並べて確認できます。

## 基底展開の積分領域

ex08のHernquist最低次の例で、積分上限を10、30、100と変え、半径格子も細分化して比較してください。角度格子・次数を固定し、半径方向の切断誤差と積分誤差を切り分けます。一様球では境界の不連続性と有限次数の誤差も残るため、半径格子だけで完全に一致するとは限りません。
