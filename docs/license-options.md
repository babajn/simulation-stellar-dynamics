# ライセンス候補

まだライセンスを適用していません。原Notebookの教育目的・免責の記載は保持していますが、それだけでは再利用・改変・再配布の許諾範囲が確定しません。著作権者と、他者のコードや文章を含まないことを著者に確認した後に選択します。

候補は次の2案です。

1. コードと文章をまとめてMIT：運用が単純です。著作権表示・許諾表示を維持して再利用できます。[MIT本文](https://opensource.org/license/mit)
2. コードセル・scriptsをMIT、説明文・docsをCC BY 4.0：教材文章の出典と改変表示を明確にできます。Notebook内の適用境界を明記します。[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)

いずれも商用利用を許す候補です。どちらを選ぶか、著作権者名と対象年、原文の「教育目的のみ」との整合性を採用前に確認します。採用後に正式なLICENSEファイルを配置します。第三者の論文・図・資料に一括適用しません。
