## 数式の正誤表


### 17ページの時刻の定義

各時刻の式が `t_n = t_0 + Σ_{n=0}^{N−1} h_n` となっており、添字が衝突し、どの時刻も最終時刻になっています。可変刻みなら次の式に直します。

$$t_n=t_0+\sum_{k=0}^{n-1}h_k.$$

独立変数を時刻とする説明なので、区間も `[x_0,x_N]` から `[t_0,t_N]` に統一します。

### 47ページの緩和時間

Coulomb対数の最後の近似式で対数が欠落しています。スライドの近似を用いるなら、

$$\ln\Lambda=\ln\left(\frac{b_{\max}}{b_{90}}\right)\simeq\ln\left(\frac{Rv^2}{Gm}\right).$$

また、遭遇率を掛けた積分は速度変化の二乗そのものではなく、単位時間当たりの増加率です。`D_perp = d⟨(Δv_perp)²⟩/dt` と定義して `t_relax ≃ v²/D_perp` と書くと次元が一致します。下段の `0.1 N/ln N × t_cross` という代表的なスケーリングを否定する指摘ではありません。

### 61ページのHermite多項式

下段の加速度多項式で、一次の項の係数が `a_n` になっています。正しくはjerkの `dot a_n` です。

$$a^{\rm poly}(t)=a_n+\dot a_n(t-t_n)+\frac12a_n^{(2)}(t-t_n)^2+\frac16a_n^{(3)}(t-t_n)^3.$$

同じページの `v_poly(t)` と `x_poly(t)` の積分上限も、一般の時刻を表すなら `t_{n+1}` から `t` に変更し、積分変数を `τ` とします。端点だけを表すなら、左辺と右辺をともに `t=t_{n+1}` に統一します。

### 73ページのTree法

セルについて和を取る右側の式で、質量が粒子の `m_j` のままです。セルの総質量 `M_k` と質量中心 `X_k` を使い、自己粒子を含むセルは開くことを明記します。

$$\mathbf a_i\simeq\sum_{k\in\mathrm{accepted}}GM_k\frac{\mathbf X_k-\mathbf x_i}{|\mathbf X_k-\mathbf x_i|^3}.$$

### 86–87ページの基底関数展開

密度・ポテンシャルの展開に係数 `A_nlm` がありません。基底が固定されているなら、両方の式に同じ展開係数が必要です。

$$\rho(\mathbf x)=\sum_{nlm}A_{nlm}\rho_{nl}(r)Y_{lm}(\Omega),\qquad
\Phi(\mathbf x)=\sum_{nlm}A_{nlm}\Phi_{nl}(r)Y_{lm}(\Omega).$$

87ページも、係数を残した線形方程式に直します。球面調和関数を正規直交化している場合、

$$s_{nlm}=\int\Phi_{nl}^*(r)Y_{lm}^*(\Omega)\rho(\mathbf x)\,d^3x
=\sum_{n'}M^{(l)}_{nn'}A_{n'lm},$$

$$M^{(l)}_{nn'}=\int_0^\infty\Phi_{nl}^*(r)\rho_{n'l}(r)r^2\,dr.$$

現状の途中式では体積要素に由来する `r²` も欠落しています。双直交基底なら行列が対角になり、係数を求められる、という説明につなげます。[Hernquist & Ostriker (1992)](https://adsabs.harvard.edu/pdf/1992ApJ...386..375H) の展開式とも対応します。

### 95–96ページの星形成則

`dρ_SF/dt = c_star ρ_gas^(1/2)` は、`c_star ≈ 0.03` を無次元の効率とする記述と次元が合いません。引用されているモデルの形は、

$$\dot\rho_\star=c_\star\frac{\rho_{\rm gas}}{t_{\rm dyn}},\qquad t_{\rm dyn}\propto(G\rho_{\rm gas})^{-1/2},$$

したがって密度依存性は `ρ_gas^(3/2)` です。指数だけでなく、時間尺度を含む上式に置き換えるのが適切です。[Saitoh et al. (2008), 式1](https://arxiv.org/pdf/0802.0961)

星形成条件の `ρ_gas > 100 H/cm³` は質量密度と数密度を混同するため、`n_H > 100 cm⁻³` と表記します。

### 102ページの三次方程式の根

`x³−x−2=0` の複素根 `−0.26 ± 1.53i` は誤りです。正しくは、

$$x\simeq1.52137971,\qquad x\simeq-0.76068985\pm0.85787363i.$$

数値的に求めた根を元の多項式へ代入し、倍精度で最大残差約 `9.8×10⁻15` を確認しました。実根の近似値1.52は正しいです。

### 113ページの中心差分法の解

特性根がそのまま解として書かれています。二段階漸化式の一般解は、

$$y_n=C_+r_+^n+C_-r_-^n,\qquad r_\pm=-\alpha h\pm\sqrt{1+\alpha^2h^2}.$$

二つの初期値が係数を決めます。`α>0, h>0` では片方の根の絶対値が1を超えるため、減衰試験方程式に対して不安定という結論は正しいです。

## 説明と改訂Notebookをそろえる箇所

| ページ | 補足・修正内容 |
|---|---|
| 19・26–28 | 二段階の中心差分法を指すMidpointと、RK2の陽的中点法を区別する。Modified Eulerという名称には文献差があるため、式と「explicit midpoint」を併記する。 |
| 20・22・25 | 局所誤差は、そのステップを厳密解から開始した場合の誤差であると明記する。一般の累積誤差 `y(t_{n+1})−y_{n+1}` と区別する。 |
| 35–40 | 有限回の予測修正と、陰的Adams–Moulton方程式を収束まで解く方法を区別する。4次AMや1回修正のPECEを、一般に硬い方程式向けと説明しない。 |
| 38・40 | 「2回／ステップ」は過去の導関数を保存するPECE実装のコストとして説明する。現在の実演コードは過去値を再計算し、ABM4で5回、ABM2で3回。教材の時間測定は理論上の最小コスト比較ではない。 |
| 53・58–59・65 | シンプレクティック性は真のエネルギーの厳密保存ではない。円軌道ではエネルギー誤差に特別な相殺があり、そこから解法の次数を判定しない。改訂Notebookの位置誤差とエネルギー誤差を分けた図に更新する。 |
| 55–56 | Leapfrogの1回／ステップという説明は、加速度を再利用する現在の実装と整合している。初回の加速度計算は別途必要。 |
| 62–64 | Hermiteの1回／ステップは加速度とjerkを同時に評価することを意味する。加速度だけの評価と同じ計算量ではなく、速度優位は実装・問題に依存する。 |
| 70・90 | 直接和の「accuracy: perfect」を「粒子間重力の集約近似をしない」に変更する。丸め誤差、粒子化、softeningや時間積分に由来する誤差は別に存在する。 |
| 77 | Treeの平均相対誤差に加え、現在のNotebookにある中央値・最大相対誤差・最大絶対誤差を案内する。適切な開き角は分布・精度要求に依存し、0.1–0.3を普遍的な推奨値としない。 |
| 81–82 | 周期境界では平均密度を除いた `ρ−ρ̄` を源とし、`k=0` モードの処理を説明する。`−4πGρ̃/k²` をゼロモードにも適用してはいけない。計算量は粒子数 `N_p` と格子点数 `N_g` を区別して `O(N_p+N_g log N_g)` とする。 |
| 88 | スライドとNotebookで基底の `√(4π)` の規格化が異なる。規格化の変更自体は誤りではないが、係数も対応して変える必要がある。単位系、`K_nl`、半径スケール、有限積分上限を説明する。 |
| 110 | Simpson公式との対応は直観的説明として扱う。一般の `f(t,y)` に対する古典RK4は、中点の段階評価を二つ持ち、単にSimpson公式を当てはめたものではない。 |
| 117 | BDF2の `O(h²)` は刻みで割った微分方程式残差の次数。22ページと同じ非正規化の局所欠損なら `O(h³)`。ゼロ安定性と整合性から大局2次に収束すると説明し、「多段階法は局所・累積誤差が同じ」と一般化しない。 |

シンプレクティック法とエネルギー誤差の関係は、[Hairer, Lubich & WannerのStörmer–Verlet法の解説](https://www.unige.ch/~hairer/preprints/gniverlet.html) が参考になります。
