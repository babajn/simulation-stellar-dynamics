# 公開対象と確認事項

公開対象は `notebooks/` の修正済み10本、`scripts/` の検証・全実行・公開点検スクリプト、README、環境定義、docs、.gitignoreです。

PDF全4本（追加の統合PDFを含む）は、ユーザー指定により内容検証から除外し、配布ファイルにも含めません。原本フォルダや親フォルダを一括アップロードしません。実行済みNotebook・GIF・キャッシュはbuild以下のローカル生成物として除外します。

原Notebookの著者名・所属・教育目的の免責文は保持しました。メールアドレスは10本から削除し、保存済み出力と環境メタデータも消去しました。原本の画像出力は公開対象にありません。配布ファイルに対する検査結果は検証報告を参照してください。パターン検査は著作権の来歴や秘密情報の完全な不存在を証明しません。

## 公開設定

公開先は `babajn/simulation-stellar-dynamics`、公開範囲はPublicです。ユーザーのアップロード指示に基づく設定です。

ライセンスは未選択で、正式なLICENSEは配置していません。候補の提示だけでは許諾を付与しません。採用時に著作権者名、適用範囲、原教材の利用条件との整合性を確認します。
